## Known gaps (rusql vs MySQL 8.0)

| Area | rusql | MySQL 8.0 |
|------|-------|-----------|
| Default database | `rusql` schema | Server default / user DB |
| `information_schema` | Virtual minimal views | Full catalog |
| `SHOW CREATE TABLE` | rusql DDL export | Native DDL |
| Transactions | BEGIN/COMMIT overlay | Full ACID + isolation |
| Prepared statements | COM_STMT subset | Full binary protocol |
| Auth | caching_sha2 fast + RSA | Full plugin ecosystem |
| Aggregates / subqueries | Not implemented | Full SQL |
| Official mysql CLI vs rusql wire | INSERT may not persist across connections; UPDATE/DELETE error 1105 | Use compat_suite wire client until fixed |
| mysql-test official suite | Not ported (M30 planned) | Thousands of tests |
