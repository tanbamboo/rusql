# 引言

本书记录 **rusql** —— 一个用 Rust 实现的 MySQL 8.0 兼容数据库 —— 如何在 **AI Agent** 与 **Harness Engineering** 驱动下，按里程碑逐步建成。

它不是 Rust 教程，也不是 MySQL 内核手册。本书回答：

1. 每个里程碑在兼容之路上**解决了什么问题**
2. 我们**选择了哪种设计**、**放弃了什么**
3. **Harness**（Issue、传感器、文档、夹具）如何让自主交付仍然安全

## 读者

- 评估 Harness Engineering 是否适用于严肃项目的工程师
- 想了解 `main` 背后故事的贡献者
- 学习如何在不「一口吃成胖子」的前提下拆解数据库 MVP

## 阅读顺序

- **第一篇** — Harness 横切主题（若不熟悉 Martin Fowler 的 harness 文章，请先读）
- **第二篇** — 每个已合并里程碑一章（M0–M13）；读完第一篇后各章可独立阅读
- **附录** — 首次回顾的量化快照

## 刻意不写的内容

大段代码在仓库与 [specs](../../en/specs/) 中。[用户指南](../../zh-CN/user-guide.md) 说明如何验证当前功能。本书讲**为何**要有这些能力。
