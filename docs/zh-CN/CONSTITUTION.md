# CONSTITUTION — 不可妥协原则

英文 canonical 版本：[CONSTITUTION.md](../../CONSTITUTION.md)

## 要点摘要

1. **规格优先**：功能从明确规格开始
2. **本地门禁 = CI 门禁**
3. **文档变更影响**：实现须同步文档或说明无影响
4. **无密钥政策**
5. **Harness 进化义务**：重复失败须记录并修复 harness
6. **国际化**：`crates/` 中用户可见字符串须走 `rusql-i18n`
7. **Issue 范围纪律**：单次 PR 尽量只覆盖一个 `area:*`
